Your tickets and contractors live only in this browser. Export a copy regularly so you never lose it — import it back any time, on any device.

Downloads a JSON file with every ticket and contractor. Save it somewhere safe — email it to yourself, Drive, a USB stick, wherever you'll actually find it again.

Import Data (Merge)

Load a previously exported file and merge it in. Only adds what's missing here — never deletes or overwrites anything already on this device. Use this to bring your phone and laptop in sync, or to recover after losing data.

Import Data (Overwrite Everything)

⚠️ This DELETES everything currently on this device and replaces it with the imported file. Use Import (Merge) above unless you specifically want to wipe and replace.
